Turkey Breakout: Dinner Dash — a static canvas runner where a turkey outruns the farmer, dodges ovens and carving knives, grabs corn, and races from the farmyard into the kitchen to reach the freedom gate.

## Play

Serve the `game/` folder with any static file server and open `game/index.html` in a desktop browser. No network requests; everything runs offline.

Controls: Space / W / click to jump, S / Down to duck, Shift to sprint, Enter to start or restart.
